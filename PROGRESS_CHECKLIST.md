# 🚨 PROGRESS UPDATE CHECKLIST

## BEFORE STARTING ANY TASK:
1. ☐ Search for existing implementations
   ```bash
   grep -r "what_youre_building" .
   ```
2. ☐ Check if similar component exists
3. ☐ Review related documentation
4. ☐ Identify reusable code

## WHILE WORKING (Every 15 minutes):
1. ☐ Save your work
2. ☐ Update status in progress_tracker.md
3. ☐ Note progress percentage
4. ☐ Document any issues
5. ☐ COMMIT CHANGES!

## AFTER COMPLETING ANY TASK:
IMMEDIATELY (Within 5 minutes):

1. ☐ progress_tracker.md - Mark with ✅
2. ☐ task_plan.md - Update implementation notes
3. ☐ api_examples.md - Add/update code examples
4. ☐ database_schema.md - Note any DB changes
5. ☐ deployment_guide.md - Update deployment steps
6. ☐ CLAUDE.md - Update file lists if needed
7. ☐ README.md - Update if major feature added
8. ☐ PROGRESS_CHECKLIST.md - Check off completed

## BEFORE WRITING NEW CODE:
1. ☐ "Does this already exist?" - Search first
2. ☐ "Can I reuse something?" - Check existing components
3. ☐ "Did I write this before?" - Search all files
4. ☐ "Is there a pattern to follow?" - Review similar implementations

## CODE REUSE CHECK:
- ☐ Existing UI components? → Use/Extend them
- ☐ Existing API patterns? → Follow them
- ☐ Existing database patterns? → Reuse schema
- ☐ Existing utilities? → Use them

## COMMIT MESSAGE FORMAT:
```
feat/fix/docs: brief description

✅ Completed: [Task]
📊 Progress: X%
🔄 Reused: [existing code]
📝 Updated: [files]
🚫 Avoided duplicate: Yes
```

## DAILY END-OF-DAY:
1. ☐ Review all tasks today
2. ☐ Update overall progress
3. ☐ Plan tomorrow's work
4. ☐ Note dependencies created/cleared
5. ☐ Final commit with all changes

## ⚠️ REMEMBER:
- **NEVER write the same code twice**
- **ALWAYS update progress immediately**
- **REUSE before creating new**
- **DOCUMENT what you reused**
- **COMMIT after every update**

## 📞 EMERGENCY:
If you find duplicate work being done:
1. STOP immediately
2. Check progress_tracker.md
3. Search for existing implementation
4. Update documentation to prevent future duplicates
