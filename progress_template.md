```markdown
### ✅ Task Name
**Status**: ✅ Completed / ❌ Not Started / 🔄 In Progress
**Assigned To**: [Developer Name]
**Estimated Hours**: X
**Actual Hours**: X
**Start Date**: YYYY-MM-DD
**Completion Date**: YYYY-MM-DD
**Dependencies**: [List any dependencies]

**Tasks**:
- [ ] Sub-task 1
- [ ] Sub-task 2
- [ ] Sub-task 3

**交付物** (Deliverables):
- [ ] Deliverable 1
- [ ] Deliverable 2
- [ ] Deliverable 3

**Blockers**: [List any blockers if applicable]
- None

**Notes**:
- Any issues encountered
- Learnings or improvements
- Deviations from plan

**Code Review**:
- [x] Code reviewed by [Reviewer]
- [x] All tests passing
- [x] Documentation updated

**Pull Request**: #XXX
```

## Quick Status Guide

- ✅ **Completed**: Task is fully done and tested
- ❌ **Not Started**: Task hasn't been started yet
- 🔄 **In Progress**: Currently being worked on
- ⚠️ **Blocked**: Waiting for dependencies or issues resolved
- 🔶 **In Review**: Code is ready for review
